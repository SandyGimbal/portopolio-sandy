# 🌐 Sandy — Cyberpunk GIS & Medical Informatics Portfolio

Portofolio web futuristik bertema **Cyberpunk Sci-Fi HUD** yang memadukan keahlian **Sistem Informasi**, **Medical Informatics**, dan **Geospasial GIS (Geographic Information System)**.

---

## ⚡ Fitur Utama

- 🌍 **True 3D WebGL Holographic Globe (Three.js)**: Globe interaktif 3D dengan rotasi inertia, orbit satelit GIS, dan cloud node spasial WGS84.
- 💓 **Live Medical ECG Waveform (HTML5 Canvas)**: Telemetri denyut jantung dan monitor vital stabil real-time.
- 💻 **Interactive Cyber Terminal CLI**: Emulator konsol baris perintah interaktif (`help`, `bio`, `skills`, `exp`, `sat`, `goto <page>`, `date`, `time`, `clear`).
- 🚀 **Multi-Page SPA Architecture**: Navigasi halaman mandiri (*Home*, *Keahlian*, *Pengalaman & Proyek*, *Terminal*, *Kontak*) dengan efek *Holographic Scan Beam*, *Section Focus Pulse*, dan audio synthesizer.
- 📱 **100% Responsif Mobile & Desktop**: Desain ramah sentuhan, mobile bottom quick-dock, dan timeline sirkuit neon tanpa horizontal clipping di semua resolusi layar.
- 🔊 **Web Audio Synthesizer**: Efek suara futuristik bawaan tanpa dependensi file audio eksternal.

---

## 🛠️ Tech Stack

- **Markup & Layout**: HTML5, Tailwind CSS (CDN)
- **3D Graphics**: Three.js (r128 WebGL)
- **Audio Engine**: Web Audio API (Dual-tone Oscillator Synthesizer)
- **Typography**: Orbitron, Fira Code, Plus Jakarta Sans (Google Fonts)
